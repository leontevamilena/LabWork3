# Практическая работа по системе контроля версий

## Название проекта

Изучение работы в системе контроля версий.

## Описание

Данный проект создан в рамках выполнения практической работы.
Цель работы — изучить основные возможности системы контроля версий,
научиться создавать файлы репозитория, выполнять фиксацию изменений
и загружать файлы в удалённый репозиторий Gitea.

В ходе работы рассматриваются:

- создание файлов репозитория;
- написание файла README.md;
- настройка файла .gitignore;
- добавление файлов в репозиторий;
- создание коммитов;
- загрузка файлов в удалённый репозиторий.

## Инструкции по установке

Для работы с проектом необходимо:

1. Установить Git.
2. Открыть командную строку или терминал.
